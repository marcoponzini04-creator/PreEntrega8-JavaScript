
# Pre-Entrega 8 - JavaScript

## Simulador de venta de entradas

Proyecto desarrollado para el curso de JavaScript de Coderhouse.

### Descripción

Aplicación web que permite administrar entradas para un evento mediante una interfaz interactiva.

### Funcionalidades

- Visualizar entradas disponibles.
- Agregar nuevas entradas mediante un formulario.
- Buscar entradas por tipo.
- Eliminar entradas.
- Vender entradas y actualizar el stock.
- Identificar entradas disponibles y agotadas.
- Vaciar todas las entradas.
- Guardar y recuperar datos mediante localStorage.

### Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

### Conceptos aplicados

- Manipulación del DOM.
- Eventos.
- Arrays y objetos.
- Clases.
- Métodos de arrays.
- JSON.parse() y JSON.stringify().
- Persistencia de datos con localStorage.
- Operador ternario.
- Operador de fusión nula (??).
- Destructuring de objetos.

### Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Ejecutar index.html mediante Live Server.

Los cambios realizados en las entradas se conservan en el almacenamiento local del navegador.
